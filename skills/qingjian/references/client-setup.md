# 连接与客户端配置

## 先判断哪一环

1. 当前Agent能发现轻笺工具并成功调用info：已接入，无需重复配置。
2. 工具缺失：检查实际运行的客户端和环境；Windows本机的localhost不等于云端localhost。配置存在不代表当前会话已加载。
3. 工具存在但调用失败：区分软件未运行/接口未开启、401令牌错误、网络拒绝、TLS问题；不得输出凭据。
4. 配置后重新加载客户端，发现工具并调用info才完成验收。只读验收不创建测试任务。

## 首次配置

先确定用户实际使用的客户端、操作系统、轻笺实例和配置路径。优先使用客户端正式配置入口。只在授权与权限允许时修改，备份并保留其他配置；受限时给本机操作步骤，不绕过限制。不要默认云端能访问本机，不自动开放远程、端口或防火墙。

本机默认 http://127.0.0.1:49321/mcp ，实际地址以轻笺界面为准；Streamable HTTP，静态 Bearer认证，不是OAuth。令牌从用户选择的轻笺实例本机配置安全读取或由用户在客户端中填写，不发给Agent对话。配置模板中的占位符必须由本机替换，不能当有效配置。

### Codex

使用当前安装客户端支持的 MCP 配置格式。已验证格式：

```toml
[mcp_servers.qingjian]
url = "http://127.0.0.1:49321/mcp"
http_headers = { Authorization = "Bearer <LOCAL_TOKEN>" }
```

将令牌留在本机用户配置，勿放进项目仓库。写入之前备份并解析验证，不能用整份模板覆盖已有配置。客户端支持环境变量或凭据辅助程序时可使用其正式机制。令牌轮换后更新引用。

### 其他Agent

按其正式支持的Streamable HTTP与Authorization头配置方式接入；不要将Codex TOML照搬。只支持stdio的客户端不能直接使用HTTP地址，不自动安装第三方桥接器。具体客户端未验证前标注“未验证”，不能承诺跨客户端已测试通过。

## 辅助检查脚本

`scripts/check_connection.py --app-dir <轻笺目录>`：本机读取选定实例的data/mcp-config.json，只做初始化、工具发现和info读取，不输出令牌或任务标题，不写任务。需要Python3.10+。脚本通过只证明该脚本所在主机到软件可通；仍须在Agent客户端发现并调用工具。

未经用户明确要求，不为验收新增、完成或删除任务。远程HTTPS证书校验必须保留；不通过禁用TLS验证修复连接。
